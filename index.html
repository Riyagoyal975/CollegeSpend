📐 Functions & Input-Output Mapping

Composite Function Evaluator: $(h \circ g \circ f)(x)$

Let $f(x)$ be the raw transaction expense, $g(x) = 5\%\text{ GST / platform surcharge}$, and $h(x) = \text{Remaining Budget} - (f(x) + g(x))$.

🕸️ Graph Theory: Category Co-Spending Graph $G = (V, E)$

Vertices $V$ represent 7 Expense Categories. An edge $(u, v)$ connects categories spent on the same calendar day. Edge weights indicate co-occurrence frequency.

🤝 Handshaking Lemma Verification Theorem

In any undirected graph, the sum of all vertex degrees is exactly twice the number of edges: $$\sum_{v \in V} \deg(v) = 2 \cdot |E|$$

📖 Project Information & Viva Examiner Notes

Project Title: CollegeSpend – Smart College Daily Expense Tracker

Course: B.Tech 3rd Semester Computer Science & Engineering

Subject: Discrete Mathematics (MA301 / CS302)

How to Demonstrate in Viva:

  1. Set Theory: Open Discrete Math Lab → Set Theory tab. Show Union, Intersection, Difference, and the Principle of Inclusion-Exclusion formula verified in real time.
  2. Relations: Switch to Relations tab. Demonstrate the 7×7 binary matrix, check Reflexive, Symmetric, and Transitive tests for equivalence.
  3. Functions: Show the mapping of expenses to categories. Demonstrate why $f$ is Not Injective using the Pigeonhole Principle.
  4. Propositional Logic: View live financial truth evaluations ($P, Q, R, S$). Generate the 2-variable and 3-variable truth table and classify formulas as Tautologies.
  5. Graph Theory: View the HTML5 Canvas co-spending graph. Point out vertex degrees and show the Handshaking Lemma $\sum \deg(v) = 2|E|$ verified dynamically.
